# Boki Learning Platform 🎓

Boki Learning Platform is an engaging, modern, and highly interactive educational portal designed to make learning a joyful experience. Featuring a playful **Claymorphism** UI, dynamic animations, and seamless dark mode integration, Boki ensures an intuitive experience for both students and administrators.

## ✨ Features

### 👨‍🎓 For Students
- **Interactive Dashboard**: View course progress, upcoming lessons, and recent achievements.
- **Engaging Lessons**: Rich-content lesson viewer designed for focus and readability.
- **Dynamic Quizzes**: Interactive quiz interface with instantaneous feedback.
- **Results Tracking**: Comprehensive result summaries and performance tracking.

### 👨‍🏫 For Administrators
- **Analytics Dashboard**: High-level overview of student performance and platform engagement.
- **Lesson Management**: Create, edit, and organize educational content.
- **Question Bank**: Manage quiz questions, answers, and difficulty levels.
- **Result Monitoring**: Monitor student grades, test outcomes, and detailed analytics.
- **Student Management**: Oversee student accounts and progress.

## 🎨 UI/UX Features
- **Claymorphism Design System**: Soft, 3D-like, playful card designs with vibrant colors.
- **Dark Mode Support**: Seamless toggle between light & dark themes across all pages.
- **Responsive Layouts**: Optimized for seamless navigation on both desktop and mobile devices.
- **Micro-Animations**: Smooth hover effects and transitions.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/TLN606/boki-learning-platform.git
```

### 2. Switch to Demo Branch (If exploring V1.0)
```bash
git checkout demo-v1.0
```

### 3. Run the UI Redesign
Navigate to the `ui-premium-redesign-v1/` directory and open `index.html` in your favorite web browser or start a local live server.

### 4. Backend Setup
Open `Boki_ELearning.slnx` or `.csproj` using Visual Studio to run the ASP.NET backend.

## 🛠️ Tech Stack
- **Frontend Design**: HTML5, Vanilla JS, CSS3, SVG Icons.
- **Backend Framework**: C# / ASP.NET.

## 📄 Branching Strategy
